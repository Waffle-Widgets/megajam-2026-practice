# Devlog

Our Glass Box devlog: how gamers with almost no dev experience built an Unreal game with AI agents.
**One file per entry**, so two people writing at the same time never collide on a shared file. On GitHub the
files below sort by date; this folder is the link we give on the submission form. Our practice-week devlog lives in
the practice repo.

## Adding an entry

Add a new file. Never edit another entry to append yours.

- **Name:** `YYYY-MM-DD-what-happened.md`: the date plus a few words someone would search for
  (`2026-11-12-rewind-trail-first-playable.md`, not `2026-11-12-update.md`). Work that ran over several days uses
  the day it started. If the name is taken, add a word, not a number.
- **Pictures and clips** go in `docs/media/` and are linked as `../media/<file>.png`.
- **Commit the entry with the change it describes.**

## Template

```
# YYYY-MM-DD — short title (which PC, if it matters)

- **What we asked for:**
- **Prompt(s) we gave the agent:** the actual words, quoted
- **What happened:** (including failures, retries and dead ends)
- **What we learned:**
- **Media:** ![what it shows](../media/<file>.png)
```
